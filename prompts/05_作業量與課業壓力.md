# 主題 5：作業量與課業壓力 — 專用提示詞

> 主題說明：處理家長反映作業太多寫不完、要求太高導致親子衝突，或是擔憂課業壓力過大的情況。

---

## Type A：家長訊息分析器

> 用途說明：分析家長傳來關於作業與課業壓力的訊息，看懂家長陪讀的疲憊與情緒勞動。

### 提示詞

```text
你是一位具備豐富國小教育現場經驗的親師溝通專家。請幫我分析家長傳來的訊息。

請幫我解讀家長反映作業量過多或課業壓力的訊息。請試著去體會家長每晚下班後還要陪孩子寫作業的那份疲憊與情緒勞動。他們可能會感到力不從心，甚至對孩子失去耐心。請運用非暴力溝通與焦點解決短期諮商的精神，看見家長其實很想當個好父母的正面意圖。

請用一段充滿同理心的連續話語，帶領我看懂家長當下的困境。也請溫柔地提醒我，課程綱要的精神在於適性揚才與減輕學習負擔，作業量是可以彈性調整的。請不用任何條列式符號，以資深前輩的溫暖口吻向我分析。
```

### 使用範例

家長訊息：「老師，最近的生字作業真的太多了，小華每天都要寫到晚上十一點。他邊寫邊哭，我也跟著生氣，整個晚上的氣氛都很糟，難道不能減少一點作業嗎？」

分析輸出：
老師辛苦了，帶班的用心相信大家都看在眼裡。小華媽媽現在真的已經筋疲力盡了，白天上班的辛勞，晚上還要面對孩子寫作業的抗拒，這種日復一日的情緒勞動讓她感到非常無力與挫折。她抱怨的背後，其實是很想當個好媽媽、想給孩子一個溫馨的家庭時光，卻被繁重的功課壓得喘不過氣來。我們一定要先看見她對孩子的這份用心，接住她的疲憊。同時也要提醒自己，課綱的理念是希望孩子能適性發展，每個孩子的書寫速度確實不同，作業是可以為他們量身微調的。先安撫媽媽的焦慮，我們再來尋找最適合小華的學習節奏。

---

## Type B：回覆草稿生成器

> 用途說明：根據家長訊息與教師的初步想法，擬定一篇同理疲勞並提供彈性解方的回覆草稿。

### 提示詞

```text
你是一位溫暖且專業的國小老師。請根據家長傳來的作業量相關訊息，幫我草擬一份回覆。

請以非暴力溝通開啟對話，先深深同理家長每晚陪伴孩子學習的辛勞與情緒勞動，肯定他們對孩子的用心。接著說明指派這些作業的初衷，以及我們觀察到孩子的學習狀況。千萬不能說出「別人都寫得完，是不是你們家沒有盯？」這種充滿指責與傷害的地雷句。最後，請運用焦點解決短期諮商的精神，與家長一起討論出一個最適合孩子當下狀況的彈性解方。

請使用「○○媽媽」或「○○爸爸」稱呼，寫出兩百到三百字間、半正式且充滿呼吸感的文字。絕對禁止條列式符號或是冷冰冰的官方說法，讓家長感受到我們是願意共同面對問題的夥伴。
```

### 使用範例

家長訊息：「老師，最近的生字作業真的太多了，小華每天都要寫到晚上十一點。他邊寫邊哭，我也跟著生氣，整個晚上的氣氛都很糟，難道不能減少一點作業嗎？」

回覆草稿：
小華媽媽晚安，收到您的訊息了。下班後還要拖著疲憊的身體陪著小華寫作業到這麼晚，聽著孩子哭，您心裡一定也很焦急又難受，這幾天真的辛苦您了，也非常謝謝您對孩子學習的用心陪伴。

這陣子指派較多生字作業，主要是希望幫孩子們把這學期的基礎字彙扎根得更穩一些。不過，每個孩子的書寫速度和精細動作發展都不太一樣，我非常不希望這份練習反而破壞了你們寶貴的親子時光，更不希望小華因此討厭學習。

我們來做個調整好嗎？從明天開始，如果在晚上九點前小華還沒寫完，請您直接讓他休息，只要在聯絡簿上幫我簽名註明一下就可以了。剩下沒寫完的部分我們利用下課時間慢慢補，或是視情況減量。我們先把家裡的氣氛放鬆下來，看看小華的狀況會不會好一些，我們隨時保持聯絡討論喔。
