# 主題 10：LINE 群組溝通禮儀與界線 — 專用提示詞

> 主題說明：處理 LINE 群組中的深夜傳訊、公開指控或情緒發言，掌握轉化溝通場域的技巧。

---

## Type A：家長訊息分析器

> 用途說明：分析群組中情緒性訊息的成因，提供冷靜降溫與保護親師群體的策略。

### 提示詞

```markdown
你是一位精通危機處理與非暴力溝通的教育專家。請幫我分析這則在 LINE 群組中發生的家長訊息。
在群組這種公開場域，家長可能會因為焦慮而要求即時回應，或者不小心發表了帶有指控意味的言論。
請用溫暖且冷靜的前輩口吻，幫我分析家長背後的焦慮與群體效應的潛在風險。
分析結果請寫成自然流暢的段落，絕對不要使用任何條列式或標號。
請先同理家長的急迫感，同時提醒我個資法與公開場域可能引發的法律風險。
請特別指出最危險的地雷：絕對不能在群組裡跟家長公開爭論或辯解。請指導我如何冷靜降溫，並將溝通場域安全地轉移到私訊或實體面談。
```

### 使用範例

**家長訊息**：（晚上十一點半在班級群組）「請問老師，今天小強在班上被打是怎麼回事？對方家長不用出來道歉嗎？學校到底有沒有在管？」

**期待的分析輸出風格**：
這位媽媽在深夜傳出這樣的訊息，可見她當下真的是氣壞了，充滿了保護孩子的焦慮與心急。在這種情緒高點，她可能沒留意到群組是一個公開的場域，這樣發言不僅可能會引起其他家長的恐慌，也可能會有侵犯隱私的問題。我們現在最重要的工作是冷靜降溫，千萬不要在群組裡直接跟她解釋事情的來龍去脈，這很容易演變成公開的筆戰，而且對兩個孩子都不公平。我們需要先接住她的著急，讓她知道我們看到了，然後溫和堅定地把這段對話拉回私底下的空間，給彼此一個冷靜且安全的溝通環境。

## Type B：回覆草稿生成器

> 用途說明：生成在群組中得體降溫、並將對話轉入私下溝通的安全回覆草稿。

### 提示詞

```markdown
撰寫回覆時，請將非暴力溝通（NVC）的「觀察、感受、需要、請求」四步驟內化為內部寫作思維：
1. 觀察：客觀說明考量個人資料保護與事件完整釐清之事實需求；絕對不在群組公開議論未經雙方確認之學生個資或事件細節。
2. 感受：在群組中簡單且穩定地同理家長的心急與焦慮，表達老師已收到訊息。
3. 需要：回應家長希望孩子問題獲處理、以及保護學生隱私與維持親師群組和諧的核心需要。
4. 請求／下一步：提出轉為私訊、電話或隔日面談溝通的具體下一步；絕不在群組與家長公開爭論或辯解。

請務必將上述 NVC 四步驟自然融合為 2～3 段具呼吸感、長短句自然交錯的半正式連貫文字，字數控制在 200 到 300 字之間。稱呼請用「○○媽媽」或「○○爸爸」，不使用「家長您好」。
絕對禁止對家長輸出「觀察」、「感受」、「需要」、「請求」等標題、學術術語、條列式、數字標號或生硬的官方詞彙。請讓群組裡的其他家長看到老師處理事情的穩健態度，同時保護當事人隱私。
```

### 使用範例

**家長訊息**：（晚上十一點半在班級群組）「請問老師，今天小強在班上被打是怎麼回事？對方家長不用出來道歉嗎？學校到底有沒有在管？」

**期待的回覆草稿輸出風格**：
小強媽媽，這麼晚了還讓您掛心這件事，真的很不好意思，我完全能感受到您現在心疼又焦急的心情。孩子在學校發生摩擦，作為家長一定會想要馬上了解清楚狀況。因為這件事情牽涉到孩子們相處的細節，為了保護孩子們的隱私，也為了能更完整地跟您說明整個經過，我們比較不適合在群組這邊討論。我已經先把這件事記在心上了，明天早上我會第一時間給您打電話，我們好好地聊一聊，釐清整個狀況。今晚先請您稍微放寬心，好好休息，我們明天早上見。
