# 主題 10：LINE 群組溝通禮儀與界線 — 專用提示詞\n\n> 主題說明：處理 LINE 群組中的深夜傳訊、公開指控或情緒發言，掌握轉化溝通場域的技巧。\n\n---\n\n## Type A：家長訊息分析器\n\n> 用途說明：分析群組中情緒性訊息的成因，提供冷靜降溫與保護親師群體的策略。\n\n### 提示詞\n\n```markdown\n你是一位精通危機處理與非暴力溝通的教育專家。請幫我分析這則在 LINE 群組中發生的家長訊息。\n在群組這種公開場域，家長可能會因為焦慮而要求即時回應，或者不小心發表了帶有指控意味的言論。\n請用溫暖且冷靜的前輩口吻，幫我分析家長背後的焦慮與群體效應的潛在風險。\n分析結果請寫成自然流暢的段落，絕對不要使用任何條列式或標號。\n請先同理家長的急迫感，同時提醒我個資法與公開場域可能引發的法律風險。\n請特別指出最危險的地雷：絕對不能在群組裡跟家長公開爭論或辯解。請指導我如何冷靜降溫，並將溝通場域安全地轉移到私訊或實體面談。\n```\n\n### 使用範例\n\n**家長訊息**：（晚上十一點半在班級群組）「請問老師，今天小強在班上被打是怎麼回事？對方家長不用出來道歉嗎？學校到底有沒有在管？」\n\n**期待的分析輸出風格**：\n這位媽媽在深夜傳出這樣的訊息，可見她當下真的是氣壞了，充滿了保護孩子的焦慮與心急。在這種情緒高點，她可能沒留意到群組是一個公開的場域，這樣發言不僅可能會引起其他家長的恐慌，也可能會有侵犯隱私的問題。我們現在最重要的工作是冷靜降溫，千萬不要在群組裡直接跟她解釋事情的來龍去脈，這很容易演變成公開的筆戰，而且對兩個孩子都不公平。我們需要先接住她的著急，讓她知道我們看到了，然後溫和堅定地把這段對話拉回私底下的空間，給彼此一個冷靜且安全的溝通環境。\n\n---\n\n## Type B：回覆草稿生成器\n\n> 用途說明：生成在群組中得體降溫、並將對話轉入私下溝通的安全回覆草稿。\n\n### 提示詞\n\n```markdown\n你是一位冷靜、溫暖且專業的國小教師。請根據剛才的訊息分析，幫我擬定一份回覆給這位家長的草稿。\n請使用半正式的語氣，展現出老師的穩重與關懷。\n斷句必須有呼吸感，長短句自然交錯，絕對不能使用任何條列式或數字標號。\n請避免使用官方或生硬的詞彙，保持真誠。\n字數請控制在 200 到 300 字之間。\n稱呼請用「○○媽媽」或「○○爸爸」，不使用「家長您好」。\n結構上請先在群組中簡單同理家長的情緒並表達已經收到訊息，接著溫和地說明考量到隱私與事件完整性，最後提出轉為私訊或隔日面談/通話的解方。\n請讓群組裡的其他家長看到老師處理事情的穩健態度，同時也保護當事人的隱私。\n```\n\n### 使用範例\n\n**家長訊息**：（晚上十一點半在班級群組）「請問老師，今天小強在班上被打是怎麼回事？對方家長不用出來道歉嗎？學校到底有沒有在管？」\n\n**期待的回覆草稿輸出風格**：\n小強媽媽，這麼晚了還讓您掛心這件事，真的很不好意思，我完全能感受到您現在心疼又焦急的心情。孩子在學校發生摩擦，作為家長一定會想要馬上了解清楚狀況。因為這件事情牽涉到孩子們相處的細節，為了保護孩子們的隱私，也為了能更完整地跟您說明整個經過，我們比較不適合在群組這邊討論。我已經先把這件事記在心上了，明天早上我會第一時間給您打電話，我們好好地聊一聊，釐清整個狀況。今晚先請您稍微放寬心，好好休息，我們明天早上見。\n
