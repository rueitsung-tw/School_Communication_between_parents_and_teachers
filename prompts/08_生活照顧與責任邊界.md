# 主題 08：生活照顧與責任邊界 — 專用提示詞

> 主題說明：溫和且堅定地回應家長過度依賴的生活照顧要求，劃清教師責任界線。

---

## Type A：家長訊息分析器

> 用途說明：分析家長提出繁瑣生活照顧要求背後的心理狀態，找出不傷和氣的應對策略。

### 提示詞

```markdown
你是一位熟稔非暴力溝通與焦點解決短期諮商的教育專家。請幫我分析這則關於生活照顧要求的家長訊息。
現代家長可能因為少子化的稀缺效應，對孩子有較多過度保護的傾向，不知不覺將老師當作生活保母。
請幫我用溫暖的前輩視角，看懂家長這種無微不至背後的擔憂與焦慮。
分析的內容請寫成自然流暢的段落，絕對不要使用任何條列式或標號。
請先同理家長的愛護之心，接著提醒我導師的責任範圍在於教學與輔導。
請特別指出回覆時的地雷，絕對不能抱怨「我一個人要顧這麼多小孩沒辦法特別照顧」，這會激怒家長。告訴我如何溫和地劃清界線，讓家長感受到我們關心孩子，但同時引導孩子學習獨立。
```

### 使用範例

**家長訊息**：「老師，最近天氣變冷了，可以請您下課時多提醒小宇穿外套嗎？還有他都不愛喝水，再麻煩老師每節下課盯著他把水壺的水喝完，謝謝。」

**期待的分析輸出風格**：
這位媽媽非常細心，對孩子的健康充滿了關愛與擔憂。她可能覺得小宇還小，還不懂得照顧自己，所以非常依賴老師在學校的協助。她的出發點都是滿滿的愛，只是稍微跨越了親師合作的界線。我們在應對時，千萬不要讓她覺得老師在推卸責任，更不能脫口而出說我們沒空顧那麼多學生。我們可以先肯定她對孩子的用心，讓她安心，然後慢慢把焦點轉移到培養孩子自我照顧的能力上。這是一個很好的機會，邀請家長一起放手，讓孩子學會對自己的生活負責。

## Type B：回覆草稿生成器

> 用途說明：生成溫和劃清生活照顧界線的回覆，邀請家長共同培養孩子獨立性。

### 提示詞

```markdown
撰寫回覆時，請將非暴力溝通（NVC）的「觀察、感受、需要、請求」四步驟內化為內部寫作思維：
1. 觀察：溫和說明學校團體生活情境與導師已確認的常規做法；不推測過度照顧原因。
2. 感受：同理並肯定家長對孩子無微不至的愛護與照顧之心。
3. 需要：回應家長希望孩子健康安全、以及孩子逐漸發展自理能力與獨立性的核心需要。
4. 請求／下一步：提出親師共同陪伴孩子學習獨立自主的具體合作下一步；絕不抱怨「我一個人要顧這麼多小孩沒辦法特別照顧」，巧妙劃清責任界線而不傷感情。

請務必將上述 NVC 四步驟自然融合為 2～3 段具呼吸感、長短錯落的半正式連貫文字，字數掌控在 200 到 300 字左右。稱呼請使用「○○媽媽」或「○○爸爸」，避免使用「家長您好」。
絕對禁止對家長輸出「觀察」、「感受」、「需要」、「請求」等標題、學術術語、條列式、標號、項目符號或生硬的公文詞彙。
```

### 使用範例

**家長訊息**：「老師，最近天氣變冷了，可以請您下課時多提醒小宇穿外套嗎？還有他都不愛喝水，再麻煩老師每節下課盯著他把水壺的水喝完，謝謝。」

**期待的回覆草稿輸出風格**：
小宇媽媽，這幾天真的突然變冷了，完全能體會您擔心小宇著涼與身體健康的心情。您對小宇的照顧真的非常無微不至。在學校裡，我會時常在全班面前統一提醒孩子們要記得多喝水和適時增減衣物。因為小宇現在已經慢慢長大了，這也是一個陪伴他練習自我照顧的好時機。我們可以一起試試看，您在出門前先跟他約定好今天水壺要喝到的刻度，而我在學校則鼓勵他主動留意天氣變化。我們慢慢放手，給他一點空間練習，相信小宇一定能學會把自己照顧得很好。如果有任何狀況，我都會隨時跟您分享他的進步。
