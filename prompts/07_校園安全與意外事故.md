# 主題 07：校園安全與意外事故 — 專用提示詞

> 主題說明：處理孩子在校受傷或發生意外時的家長溝通，妥善應對咎責與焦慮情緒。

---

## Type A：家長訊息分析器

> 用途說明：解讀家長面對孩子受傷時的焦慮與憤怒，釐清潛在的究責意圖。

### 提示詞

```markdown
你是一位具備非暴力溝通與豐富親師溝通經驗的教育專家。請幫我分析這則關於校園安全或意外事故的家長訊息。
當孩子受傷時，家長往往會覺得自己的保護網失效了，這種恐懼很容易轉化為對外的憤怒與究責。
請運用積極聆聽與非暴力溝通的視角，幫我聽懂家長隱藏在生氣或質問背後的焦慮。
請留意我們需要考量校園事故責任歸屬以及國賠法的相關精神，但在分析中請用溫暖的前輩口吻來提醒我，絕對不能使用條列式或標號。
請先同理家長心疼孩子的情緒，分析他們最在意的點是什麼，並特別提醒我回覆時的地雷，絕對不能說出「小孩子跑跑跳跳難免受傷」這類會讓家長爆炸的話。措辭必須謹慎，不要隨意承認過失，但也絕對不能顯露出推卸責任的態度。
```

### 使用範例

**家長訊息**：「老師，小寶今天回家膝蓋整個破皮流血，問他他只說上體育課跌倒。體育老師都沒在看嗎？怎麼受傷了也沒人幫他擦藥？」

**期待的分析輸出風格**：
這位媽媽現在一定非常心疼，看到孩子帶著傷回家，任何父母都會感到自責與焦慮，進而想知道學校到底發生了什麼事。她的質問其實是在表達對孩子安全的強烈在乎，同時也覺得學校好像沒有給予足夠的照顧。我們在處理這類事件時要格外謹慎，千萬不要對她說小孩子跑跑跳跳難免受傷，這會讓她覺得我們在推卸責任。我們可以先承接住她的心疼，讓她知道我們同樣不捨孩子受傷，然後再客觀地釐清事情經過。不用急著定論是誰的錯，最重要的是展現我們對孩子傷勢的關心與後續處理的誠意。

## Type B：回覆草稿生成器

> 用途說明：生成妥善處理校園受傷事件的溫暖回覆，既表達關心也不逾越法律與責任界線。

### 提示詞

```markdown
你是一位溫暖且專業的國小教師。請根據剛才的訊息分析，幫我擬定一份回覆給這位家長的草稿。
撰寫回覆時，請將非暴力溝通（NVC）的「觀察、感受、需要、請求」四步驟內化為內部寫作思維：
1. 觀察：溫和且客觀說明目前已掌握確認的事故狀況與關懷處置；未經確認之經過承諾釐清，絕不隨意猜測或盲目承諾法律責任過失。
2. 感受：深深同理家長心疼孩子受傷與擔憂的情緒，接住對方焦慮，不得擅自預設或推定家長自責等未提及之心理狀態。
3. 需要：回應家長對於孩子生命安全受保障、受妥善照顧與資訊透明的核心需要。
4. 請求／下一步：提出關心傷勢、關懷追蹤與預防說明的具體下一步合作；絕對不能說出「小孩子跑跑跳跳難免受傷」這類地雷句。

請務必將上述 NVC 四步驟自然融合為 2～3 段具呼吸感、長短句交錯的半正式連貫文字，字數控制在 200 到 300 字之間。稱呼請用「○○媽媽」或「○○爸爸」，不使用「家長您好」。
絕對禁止對家長輸出「觀察」、「感受」、「需要」、「請求」等標題、學術術語、條列式、數字標號、項目符號或「茲因」、「依據本校規定」這類生硬公文語氣。請讓家長感受到我們是一起保護孩子的團隊，而非站在對立面。
```

### 使用範例

**家長訊息**：「老師，小寶今天回家膝蓋整個破皮流血，問他他只說上體育課跌倒。體育老師都沒在看嗎？怎麼受傷了也沒人幫他擦藥？」

**期待的回覆草稿輸出風格**：
小寶媽媽，看到您描述小寶的傷口，我心裡也非常不捨，完全能體會您有多麼心疼。孩子在學校受了傷卻沒有及時得到妥善的包紮，這確實會讓人感到著急與擔憂。剛剛我已經先聯繫了體育老師與健康中心，了解到當時因為班上正好在進行分組測驗，可能沒能第一時間察覺到小寶跌倒。我為這點疏忽對您感到抱歉。小寶現在的傷口還會痛嗎？明天早上小寶到校後，我會親自帶他去健康中心給護理師重新檢查並換藥，也會好好安撫他的情緒。後續我會與體育老師共同留意上課的安全狀況，有任何情況我都會第一時間跟您聯繫。
