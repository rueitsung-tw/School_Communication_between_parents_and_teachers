# 主題 06：特殊生權益與融合教育 — 專用提示詞

> 主題說明：處理班級中特殊生與一般生家長之間的權益衝突與融合教育挑戰。

---

## Type A：家長訊息分析器

> 用途說明：分析家長（包含特殊生家長或一般生家長）的訊息，找出背後的情緒與訴求，避免誤觸地雷。

### 提示詞

```markdown
你是一位深諳國小親師溝通與融合教育的資深教育專家。請幫我分析這則來自家長的訊息。
這位家長可能是特殊生的家長，也可能是一般生的家長。請先辨識他的角色，再進行分析。
特殊生家長通常渴望孩子能被完全接納，而一般生家長則擔心孩子的學習權益受到影響。
請運用 GROW 模型與積極聆聽的技巧，幫我找出家長字裡行間未說出口的擔憂。
請特別留意，不要預設任何一方的對錯。特殊教育法與學生輔導法的核心精神是支持與理解。
分析結果請不要使用任何條列式或標號，請像一位溫暖的前輩對我說話，用自然有呼吸感的段落呈現。先同理家長的狀態，再分析他的真實訴求，最後提醒我回覆時絕對不能踩到的地雷，例如對特殊生家長說出「要不要考慮轉班」，或對一般生家長說「你要多包容」。
```

### 使用範例

**家長訊息**：「老師，那個小明上課一直大叫，我家小華回家說他都聽不到老師上課。這樣下去成績退步怎麼辦？學校不能處理一下嗎？」

**期待的分析輸出風格**：
這位媽媽看起來非常焦慮，她心疼孩子上課受到干擾，更擔心學習成效受到影響。她其實是在向你求救，希望你能保障她孩子的學習權。從她的語氣中可以感受到一點無力感，因為她不知道學校能提供什麼協助。我們在處理時要非常小心，千萬不要讓她覺得我們在偏袒特殊生，更不能用「他有特殊狀況你要多包容」這種話來搪塞她，這只會讓她覺得自己的權益被犧牲了。我們可以先接住她的擔憂，讓她知道我們也很在乎小華的上課狀況。

---

## Type B：回覆草稿生成器

> 用途說明：根據 Type A 的分析結果，生成溫暖且具備同理心的回覆草稿。

### 提示詞

```markdown
你是一位溫暖且專業的國小教師。請根據剛才的訊息分析，幫我擬定一份回覆給這位家長的草稿。
請務必維持半正式的語氣，就像一位有經驗的老師在跟家長真誠對話。
斷句要有呼吸感，長短句交錯。絕對不能使用條列式、123標號或是項目符號。
請不要出現「依據本校規定」這種官方語氣。
內容請控制在 200 到 300 字之間。
稱呼請使用「○○媽媽」或「○○爸爸」，不要用冷冰冰的「家長您好」。
結構上請先同理並接住家長的情緒，接著溫和地說明目前班上的真實狀況，最後提出具體可行的解決方案或後續支持計畫。
請記得，我們是在建立夥伴關係，而不是在為誰辯護。
```

### 使用範例

**家長訊息**：「老師，那個小明上課一直大叫，我家小華回家說他都聽不到老師上課。這樣下去成績退步怎麼辦？學校不能處理一下嗎？」

**期待的回覆草稿輸出風格**：
小華媽媽，看到您的訊息了，我完全能理解您的擔憂。小華回家能跟您分享班上的狀況，表示他很信任您，我也很心疼他上課時受到的干擾。請您放心，小華的學習權益對我來說非常重要，我一直都有在關注他上課的專注度。最近班上確實遇到了一些挑戰，我們已經啟動了輔導機制的協助，有特教老師和輔導老師一起介入幫忙。我會在課堂上調整座位安排，並隨時留意小華的聽課狀況，盡力減少對他的影響。如果有需要，我也會在下課時幫小華稍微複習重點。我們一起觀察這週的狀況，下週我再跟您通個電話討論好嗎？
