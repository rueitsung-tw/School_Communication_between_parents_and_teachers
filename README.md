# 🏫 國小親師溝通小幫手 — AI 隱形、教學顯性

本系統依據「AI 隱形、教學顯性」理念開發，專為 K-12 國小導師打造。透過將 AI 定位為「幕後工具」，降低親師溝通情緒耗損，減輕教師行政負擔。

---

## 🧠 理論與實務學理基礎 (Theoretical & Practical Foundations)

本系統的提示詞與知識卡設計並非單純的文字修飾，而是深度整合了心理學、教育哲學、溝通方法論以及中華民國教育法令的跨領域學術結晶：

### 1. 溝通與諮商方法論 (Communication & Counseling Methodologies)
*   **非暴力溝通 (Nonviolent Communication, NVC)**：基於馬歇爾·盧森堡（Marshall Rosenberg）的理論，在 Type B 回覆生成器中嚴格執行「觀察、感受、需要、請求」四步驟。系統自動產生的回覆遵循「**同理家長焦慮 → 客觀陳述班級常規事實 → 邀請親師協作解方**」的三段式結構，避免教師直接陷入自我防衛。
*   **薩提爾冰山理論 (Satir Iceberg Model)**：協助教師透過家長表面的「指責」或「超理智」行為，解碼水面下的層次——探索家長的「感受」、「期待」以及對孩子「被重視、安全感」的深層「渴望」。
*   **積極聆聽與人本諮商 (Active Listening & Client-Centered)**：引導教師運用反映（Reflecting）、釐清（Clarifying）與摘要（Summarizing）的口吻，在語氣上展現無條件的正向關懷，先「處理心情」，再「處理事情」。
*   **教練式對話 (GROW Model)** 與 **焦點解決短期治療 (SFBT)**：在特殊生與融合教育等議題中，提示詞引導雙方跳脫「是誰的錯」的泥淖，聚焦於「奇蹟問句」、「量尺問句」等尋找微小例外，並承諾本週內可執行的行動計畫。

### 2. 心理學學理 (Psychological Foundations)
*   **依附理論 (Attachment Theory)**：解碼「直升機家長」與「深夜連環傳訊者」背後的心理焦慮源於「不安全依附感」。提示詞引導教師提供「穩定、一致且可預測」的溝通回應，幫助家長在班級中建立安全堡壘，降低非理性的控制欲。
*   **歸因理論 (Attribution Theory)**：化解「基本歸因謬誤」（家長把問題外歸因給老師，老師把問題內歸因給家庭教育）。提示詞刻意將衝突焦點引導至「可控制、不穩定」的因應因素（如當下的學習方法、環境誘因），建立同舟共濟的合夥人關係。
*   **認知失調 (Cognitive Dissonance)**：當教師反映學生在校違規事實時，會挑戰家長心中「我的孩子很乖/我是個好家長」的信念，因而激發強烈否認與防衛。Type B 提示詞採用「先肯定孩子在家優點，再提供客觀在校觀察紀錄」的方式，消弭失調帶來的敵意。
*   **情緒勞動 (Emotional Labor)**：藉由 AI 將親師文字處理時間縮短 90%，並引導教師設定健康邊界（如晚上不回訊），協助將教師的表層演出（Surface Acting）轉化為健康的認知重塑，避免職業耗竭。

### 3. 教育哲學 (Educational Philosophy)
*   **Epstein 六型家長參與架構**：界定親師合作的邊界。引導家長從過度干預「決策」與「教學專業」，轉向正向支持學生的「在家學習」與「親職教育」。
*   **Bronfenbrenner 生態系統理論**：將親師關係定位在學生成長的最核心「中介系統（Mesosystem）」，唯有家庭與學校兩個「微系統」緊密接軌，孩子的學習適應力才能極大化。

### 4. 中華民國教育法令與司法判例 (Taiwanese Laws & Judicial Precedents)
提示詞與分析器內建防禦性提醒，守護親師溝通的「法定紅線」：
*   **法定責任通報**：涉及同儕衝突、自傷或家庭狀況時，自動檢索《兒童及少年福利與權益保障法》第 53 條之「24小時責任通報」與《校園霸凌防制準則》之通報調查義務，避免教師因私下協調（搓湯圓）而觸法。
*   **個資與隱私保護**：提醒教師在 LINE 班級群組中公開討論特定學生成績、違規或照片之《個人資料保護法》風險。
*   **專業自主權與管教界線**：依據《教育基本法》第 8 條（家長教育參與權）與各縣市《教師輔導與管教學生辦法》，堅守教師在教學評量、座位編排上的「專業自主權」，同時提醒避免體罰、言語羞辱等判例常見的違法行為（例如公然侮辱或逾越比例原則之判決）。

## 🌟 核心特色
1. **10 大核心主題**：涵蓋座位、成績、同儕衝突/霸凌、管教、作業、特殊生融合、校園安全等常見情境。

3. **高品質語氣約束**：草稿強制要求「半正式、溫暖、有呼吸感且不使用條列式與官方官腔」，避免教師因情緒內耗導致文字失準。

## 🛠️ 安裝與啟動步驟

### 1. 安裝環境與相依套件
本系統使用 Python 3.11+ 開發。請先確保已安裝 Python，並在專案根目錄下執行以下指令安裝套件：

```bash
pip install -r requirements.txt
```

### 2. 啟動 Streamlit 網頁應用程式
在終端機中執行以下指令以啟動本地 Web 服務：

```bash
streamlit run app.py
```
啟動後，系統會自動在您的預設瀏覽器中開啟 `http://localhost:8501`。

## 📖 使用指南

1. **設定 API 金鑰**：
   - 在左側邊欄選擇您的 AI 供應商（**OpenAI**、**Gemini** 或 **Ollama**）。
   - **Ollama (本地端)** 支援自訂伺服器網址（例如 `http://172.20.199.150:8080`），並提供選填的 API 金鑰驗證。
   - 輸入您的 API 金鑰（API Key）。
   - 選擇使用的模型種類。
   *提示：您也可以在系統環境變數中設定 `OPENAI_API_KEY`、`GEMINI_API_KEY` 或 `OLLAMA_URL`，系統會自動載入。*

2. **選擇溝通主題**：
   - 選擇對應的親師溝通主題（例如：`03 同儕衝突與霸凌處理`）。
   - 側邊欄會自動顯示該主題的 **知識卡**，包含「底層心理需求分析（薩提爾冰山）」、「教師地雷句」與「相關法令依據」，協助您在回覆前做好心態準備。

3. **貼入訊息與背景**：
   - 在左側大框中貼上家長傳來的原始訊息（例如 LINE 衝突訊息）。
   - 在右側小框中輸入教師已知的背景資訊（例如：事發經過、班規說明、已處理的進度等）。

4. **開始處理**：
   - 點擊 **「分析家長需求 (Type A)」**：AI 將分析家長的表面訴求、底層情緒與期待，並給出回覆前的法律與策略提醒。
   - 點擊 **「生成回覆草稿 (Type B)」**：AI 將依據非暴力溝通三段式結構（同理 -> 事實 -> 解方），生成有溫度的回覆草稿。您可以直接在下方的編輯框中微調，微調後複製即可。

## 📂 專案檔案結構
- `app.py`：Streamlit Web 應用的主畫面與介面邏輯。
- `utils.py`：提示詞載入解析與 LLM API 呼叫的封裝函式庫。
- `theme_taxonomy.md`：10 大親師溝通主題的知識分類庫。
- `prompts/`：存放 12 份專用/通用提示詞模組（Markdown 格式，內建 Type A 與 Type B 提示詞）。
- `research_*.md`：前期收集的四份深度研究報告，涵蓋全球主題、溝通技巧、心理學哲學、台灣法令。
