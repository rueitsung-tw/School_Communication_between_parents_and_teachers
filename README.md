# 🏫 國小親師溝通小幫手 — AI 隱形、教學顯性

本系統依據「AI 隱形、教學顯性」理念開發，專為 K-12 國小導師打造。透過將 AI 定位為「幕後工具」，降低親師溝通情緒耗損，減輕教師行政負擔。

**v2.0.0** 起已升級為**語意搜尋 RAG 架構**（ChromaDB + Ollama nomic-embed-text），支援動態新增 PDF / 文字文件，無需重啟即可自動更新知識庫索引。

---

## 🚀 v2.0.0 新功能：語意搜尋知識庫（RAG 升級）

### 核心升級
| 功能 | v1.0 | v2.0 |
|------|-------|-------|
| 知識庫機制 | 全文填入 context | **ChromaDB 向量語意搜尋** |
| 大型文件支援 | ❌ 超過 token 限制會出錯 | ✅ 支援上百 MB 的 PDF |
| 新增文件方式 | 需重啟系統 | ✅ **即時增量更新，無需重啟** |
| 文件格式 | 僅 `.md` | ✅ `.pdf` / `.txt` / `.md` 皆支援 |
| 知識注入 | 全部塞入 | ✅ **只取最相關 Top-3 段落** |

### 如何新增知識文件

1. 將 `.pdf`、`.txt` 或 `.md` 文件放入專案的 `docs/` 資料夾
2. 在側邊欄「📂 知識庫管理」面板按 **「🔄 增量更新」**
3. 完成！系統會自動提取文字、切段、向量化，並整合進下次問答

> **提示**：`watchdog` 背景監控會自動偵測新增檔案，按更新按鈕可立即觸發索引。

## 🧠 理論與實務學理基礎

本系統的提示詞與知識卡設計並非單純的文字修飾，而是深度整合了心理學、教育哲學、溝通方法論以及中華民國教育法令的跨領域學術結晶：

### 1. 溝通與諮商方法論
- **非暴力溝通 (NVC)**：在 Type B 回覆生成器中嚴格執行「觀察、感受、需要、請求」四步驟。
- **薩提爾冰山理論**：協助教師透過家長表面的「指責」，解碼水面下的「感受」、「期待」與「渴望」。
- **積極聆聽與人本諮商**：先「處理心情」，再「處理事情」。
- **教練式對話 (GROW)** 與 **焦點解決短期治療 (SFBT)**：聚焦尋找微小例外，並承諾可執行的行動計畫。

### 2. 心理學學理
- **依附理論**：解碼「直升機家長」背後的不安全依附感，引導穩定一致的溝通。
- **歸因理論**：化解基本歸因謬誤，建立親師同舟共濟的合夥關係。
- **認知失調**：以「先肯定孩子優點，再提供客觀觀察」化解家長的防衛敵意。
- **情緒勞動**：藉由 AI 將親師文字處理時間縮短 90%，避免職業耗竭。

### 3. 教育哲學
- **Epstein 六型家長參與架構**：界定親師合作邊界。
- **Bronfenbrenner 生態系統理論**：家庭與學校兩個微系統緊密接軌，孩子適應力才能極大化。

### 4. 中華民國教育法令
- 《兒童及少年福利與權益保障法》第 53 條之 24 小時責任通報
- 《校園霸凌防制準則》之通報調查義務
- 《個人資料保護法》群組隱私風險
- 《教育基本法》第 8 條教師教學專業自主權

## 🛠️ 安裝與啟動步驟

### 前置作業：遠端 Ollama 安裝 embedding 模型

在遠端 Ollama 伺服器（目前為 `172.20.10.51`）執行：

```bash
ollama pull nomic-embed-text
```

確認安裝完成：
```bash
ollama list
# 應看到 nomic-embed-text 出現在清單中
```

### 1. 安裝 Python 套件

```bash
pip install -r requirements.txt
```

主要相依套件：

| 套件 | 用途 |
|------|------|
| `streamlit` | Web 介面 |
| `openai` | Ollama / OpenAI API 呼叫 |
| `google-generativeai` | Gemini API 呼叫 |
| `pymupdf` | PDF 文字提取 |
| `chromadb` | 本地向量資料庫 |
| `watchdog` | 目錄變更監控 |

### 2. 設定 `config.json`

```json
{
  "provider": "ollama",
  "ollama_url": "http://你的伺服器IP:11434",
  "api_key": "ollama",
  "model_name": "gemma3:12b"
}
```

### 3. 啟動系統

```bash
streamlit run app.py
```

首次啟動時，系統會自動對 `docs/` 目錄下的文件進行索引（時間視文件量而定）。

## 📖 使用指南

1. **選擇溝通主題**：從下拉選單選擇對應情境，側邊欄會顯示該主題的知識卡（底層心理需求、地雷句、法令依據）。

2. **貼入訊息與背景**：
   - 左框：家長的原始 LINE / 聯絡簿訊息
   - 右框：教師已知的背景補充（選填）

3. **執行分析或生成**：
   - **「🔍 分析家長需求 (Type A)」**：AI 分析家長底層情緒、期待與法律風險。
   - **「✉️ 生成回覆草稿 (Type B)」**：依 NVC 三段式結構生成有溫度的草稿，可直接複製貼回 LINE。

4. **新增知識文件**：
   - 將 PDF / TXT / MD 放入 `docs/` 資料夾
   - 側邊欄「📂 知識庫管理」→「🔄 增量更新」
